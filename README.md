# Monitoring Suhu IoT dengan ESP32 + MQTT

Simulasi ESP32 + sensor DHT22 yang mengirim suhu dan kelembapan ke broker MQTT setiap 5 detik.

## Alur sistem
Sensor DHT22 -> ESP32 -> MQTT -> klien web

## Cara menjalankan
1. Buka proyek di Wokwi (tempel tautan proyek Anda di sini)
2. Jalankan simulasi
3. Subscribe ke topik di klien MQTT
